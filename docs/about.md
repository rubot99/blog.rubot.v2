# About

![Reuben's profile picture](assets/profile.png){ align=right width="150" }

Hi, I'm Reuben — a software engineer living in Newcastle upon Tyne. I spend
most of my working life in distributed systems, event-driven architecture,
and authentication/authorisation standards like OAuth2 and OpenID Connect —
this blog is where I write about stuff that I'm interested in that doesn't
fit anywhere else.

Outside of work I like tinkering: running a small home lab (self-hosted media
and home automation), poking at Linux distros, and experimenting with static
site generators — this blog itself has been through a few of them before
landing on MkDocs. When I'm not at a keyboard I'm usually slow-cooking
something on the kamado or working through a fermentation project.
